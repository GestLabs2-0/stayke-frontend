This repo follows the next structure: 
- src/app: where the app pages lives
- src/components: atomic components for the pages
- src/types: interfaces and types used for components
- src/lib: services used to communicate with other systems
- src/helpers: common tools used accross different components 
- src/constants: all constants used in the code
- src/context: stores all context components to use accross the code base
- src/icons: stores all icons and svgs
- src/hooks: stores all hooks used in the codebase
